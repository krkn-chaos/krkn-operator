🌐 MULTI-CLUSTER MANAGEMENT (PRIMARY: OCM)
=============================================================================

The recommended multi-cluster setup uses Open Cluster Management (OCM) with
the ManagedServiceAccount add-on enabled. This chart does not install the OCM
add-on; install and enable it on the OCM hub before configuring managed clusters.

Requirements:
  1. Register the target clusters with the OCM hub.
  2. Install the ManagedServiceAccount add-on on the hub and wait for it to be Ready.
  3. Create a ManagedServiceAccount, such as application-manager, in each managed-cluster namespace.
  4. Wait for its TokenReported condition and grant it the required permissions.

To verify the add-on, accounts, and discovered providers:
  kubectl get pods -n open-cluster-management-addon
  kubectl get managedserviceaccounts.authentication.open-cluster-management.io -A
  kubectl get krknoperatortargetproviders -n {{ include "krkn-operator.namespace" . }}

=============================================================================
